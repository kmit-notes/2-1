b) Protected
c) private

Answer: a
Explanation: Access specifier of an interface is either public or no specifier. 
When no access specifier is used then default access specifier is used due to 
which interface is available only to other members of the package in which it is declared, 
when declared public it can be used by any code.

14.Which of the following is an incorrect statement about interface?

Explanation: All methods and variables are implicitly public if interface is declared public.
