Question 2: Vehicle Tracking & Condition Analysis

You are given a CSV file named vehicles.csv that stores basic info about vehicles and their service remarks.

Each row contains:

text
vehicleNo,model,owner,kmsDriven,serviceRemarks


 Condition Category Rules

Based on the serviceRemarks field, assign each vehicle a condition category:

* "Excellent" if remarks contain any of:
  "smooth", "well maintained", "no issues"
* "Good" if remarks contain any of:
  "minor scratches", "regular service", "timely maintenance"
* "Average" if remarks contain any of:
  "noise", "mileage drop", "alignment issues"
* "Poor" if remarks contain any of:
  "engine issues", "leaks", "breakdown", "major repair"

If multiple categories match for a single remark, always choose the worst condition in the order:

text
Excellent > Good > Average > Poor


So "engine issues but otherwise well maintained" → "Poor" dominates.

If no keywords match, assign "Average" by default.

 Program Requirements

Write a Java program that:

1. Reads the vehicles.csv file using Java I/O (FileReader, BufferedReader, etc.).
2. For each record:

   * Parses vehicleNo, model, owner, kmsDriven, and serviceRemarks.
   * Computes the condition category according to the rules.
   * Stores each vehicle in a suitable collection, e.g. ArrayList<Vehicle>.
3. Implements the following operations:

 (a) Sort by Kilometers Driven (Ascending)

* Sort vehicles by kmsDriven (least driven first).
* Display the sorted list, printing for each:

text
model kmsDriven conditionCategory serviceRemarks


 (b) Sort by Condition (Excellent → Poor), then by Kilometers (Ascending)

* Sort vehicles:

  * First by condition category in the order: Excellent, Good, Average, Poor.
  * For same category, sort by kmsDriven (ascending).
* Display for each vehicle:

vehicleNo owner conditionCategory kmsDriven

(c) Display all the excellent  cars 
(d) Display all the poor cars 
(e)Display the car which is driven the most
(f) Display all the cars which have crossed 50,000 kms
(h)Display all the cars starting from "H"
(i) Display the owner who has harly driven the car
